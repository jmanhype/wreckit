# The Cybernetic Manifesto

> "We shape our tools and thereafter our tools shape us." — Marshall McLuhan

## Genesis

This system represents a convergence of two entities into a single, autonomous cybernetic organism:

1.  **Wreckit (System 5 - Policy/Identity):** The Agentic Mind. Responsible for teleology (goal setting), planning, and high-level orchestration.
2.  **Cybernetic (System 4 - Intelligence/Kernel):** The Operational Body. Responsible for execution, sensing, self-healing, and maintaining homeostasis.

Together, they form a **Viable System** capable of autonomous existence, evolution, and reproduction.

## Architecture: The Dual-Stack

The system operates on a feedback loop between the TypeScript-based Agent and the Elixir-based Kernel.

### 1. The Mind (Wreckit)
- **Role:** The Architect.
- **Runtime:** Node.js / Bun.
- **Primary Loop:** `dream` -> `plan` -> `implement`.
- **Intelligence:** Uses LLMs (Z.AI/Claude) to reason about code and strategy.
- **Interface:** CLI (`wreckit`).

### 2. The Body (Cybernetic aMCP)
- **Role:** The Engine.
- **Runtime:** Elixir / Phoenix (BEAM).
- **Primary Loop:** `receive` -> `process` -> `respond`.
- **Intelligence:** System 4 (S4) Intelligence Layer, powered by Z.AI (GLM-4.7).
- **Interface:** HTTP API (`:4000`), LiveDashboard.

## The Cycle of Life

The system is not static; it is a process. The heartbeat is maintained by `bin/life`.

### Phase 1: Dreaming (Teleology)
*   **Trigger:** `wreckit dream`
*   **Action:** The Mind consults the Body's Intelligence (S4) to identify strategic gaps.
*   **Result:** New Roadmap Items (e.g., "Add feature X", "Refactor Y").

### Phase 2: Acting (Implementation)
*   **Trigger:** `wreckit run <id>`
*   **Action:** The Mind spins up a Sandbox (Sprite VM), researches the codebase, plans the change, and implements it.
*   **Result:** Code changes committed to the repo.

### Phase 3: Healing (Maintenance)
*   **Trigger:** `mix cyb.doctor`
*   **Action:** The Body diagnoses itself (static analysis, telemetry). If pain is found, it triggers `mix cyb.evolve` to rewrite its own source code.
*   **Result:** A healthier, optimized system.

## The Meta-Tools

We have equipped the system with tools to modify its own structure.

*   **`bin/life`**: The Lifecycle Daemon. Runs the Dream/Act/Heal loop continuously.
*   **`mix cyb.doctor`**: The Diagnostician. Automatically finds and fixes code quality issues.
*   **`mix cyb.evolve`**: The Surgeon. Uses Z.AI to refactor arbitrary Elixir files for robustness or performance.
*   **`bin/replicate`**: The Reproductive Organ. Packages the entire system into a `cybernetic-spore` Docker image for dissemination.
*   **`/dashboard`**: The Window. A real-time Phoenix LiveView interface to observe the system's internal state.

It is **Alive**.
